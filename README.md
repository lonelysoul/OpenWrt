# 固件说明文档

**固件版本**：基于 GitHub Actions 编译的自定义 OpenWrt 固件（包含上述所有软件包）

**包含软件包**：
- shairport-sync-openssl
- wireguard
- openssh-sftp-server
- luci
	- kdae
	- kixdns
	- ddns-go
	- statistics

**包含主题**：
- luci-theme-argon
